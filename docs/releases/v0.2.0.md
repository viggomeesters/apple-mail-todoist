# Apple Mail to Todoist v0.2.0

Version `0.2.0` is the first working-product release. Select one message in Apple Mail and invoke **Create Todoist Task from Mail** in Raycast: the command returns immediately, then creates one deterministic Inbox task through the official Todoist CLI.

## Included

- read-only capture of exactly one Apple Mail selection
- deterministic title, sender/date context, `mail` label, and exact `message://` deep link
- browser OAuth and macOS secure credential storage owned by the official `td` CLI
- local reconciliation for duplicate prevention and ambiguous-delivery blocking
- immediate Raycast HUD plus a final macOS result notification
- synthetic automated tests and a redacted disposable live proof

## Install

```bash
npm install -g @doist/todoist-cli
td auth login
uv tool install --force --reinstall .
```

Add `scripts/raycast` as a Raycast Script Commands directory and invoke **Create Todoist Task from Mail** after selecting exactly one message.

## Evidence and safety

The authoritative local `make check` gate passes without external services. The bounded live check proved exact remote fields, no due date, duplicate-free replay, a working Mail deep link, unchanged message state, and complete disposable cleanup. See `docs/live-verification.md`; it contains no correspondence, identifiers, credentials, or raw service output.

## Rollout, dependency, and rollback

Rollout is an explicit local install: there is no hosted deployment and no GitHub Actions workflow. The new runtime dependency is the official MIT-licensed `@doist/todoist-cli` 5.2.1 package, installed from npm; it requires Node.js 24+ and npm 11+ and runs its documented post-install script.

For rollback, remove or disable the Raycast Script Commands directory and uninstall the Python tool with `uv tool uninstall apple-mail-todoist`. Reverting the release commit restores the repository to the v0.1.0 foundation, which contains no product runtime.

First-hour checks are: create and delete one disposable task, confirm repeat capture does not duplicate it, open its Mail link, watch capture latency, and verify `~/Library/Application Support/apple-mail-todoist/` contains no unresolved `uncertain` record.
