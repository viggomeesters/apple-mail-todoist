# Apple Mail to Todoist v0.1.0

Version `0.1.0` publishes the project's professional foundation: a durable product vision, testable design and safety contract, concrete architecture, local validation, public documentation, original visual identity, and nine dependency-ordered implementation tasks.

This release does not contain a live Apple Mail or Todoist adapter. That boundary is explicit so later releases can attach behavior claims to reproducible tests and redacted live evidence.

## Included

- Public repository metadata and MIT licensing
- Repo-local Go Workflow Stack `v0.3.14` contract
- Read-only Mail, Keychain, privacy, idempotency, and reconciliation principles
- Python 3.11+ package foundation with `uv`
- One-command `make check` validation
- Developer/agent onboarding and architecture documentation
- Hero and social-preview artwork

## Verify

```bash
uv sync --frozen --group dev
make check
```
